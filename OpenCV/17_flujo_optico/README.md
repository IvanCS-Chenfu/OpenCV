# Flujo óptico

Código didáctico asociado al apartado correspondiente de la wiki. Las versiones Python y C++ persiguen el mismo objetivo conceptual; no tienen por qué ser traducciones línea por línea.

## Ejecutar Python

```bash
python3 17_flujo_optico/python/main.py
```

## Compilar C++

```bash
cmake -S 17_flujo_optico/cpp -B build/17_flujo_optico
cmake --build build/17_flujo_optico
./build/17_flujo_optico/opencv_17_flujo_optico
```

> Ajusta los nombres/rutas de entrada descritos en el código. Las imágenes y vídeos seleccionados para la wiki se guardarán en `../assets/17_flujo_optico/` cuando se prepare la fase visual.
