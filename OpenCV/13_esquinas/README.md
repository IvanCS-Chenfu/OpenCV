# Harris y Shi-Tomasi

Código didáctico asociado al apartado correspondiente de la wiki. Las versiones Python y C++ persiguen el mismo objetivo conceptual; no tienen por qué ser traducciones línea por línea.

## Ejecutar Python

```bash
python3 13_esquinas/python/main.py
```

## Compilar C++

```bash
cmake -S 13_esquinas/cpp -B build/13_esquinas
cmake --build build/13_esquinas
./build/13_esquinas/opencv_13_esquinas
```

> Ajusta los nombres/rutas de entrada descritos en el código. Las imágenes y vídeos seleccionados para la wiki se guardarán en `../assets/13_esquinas/` cuando se prepare la fase visual.
