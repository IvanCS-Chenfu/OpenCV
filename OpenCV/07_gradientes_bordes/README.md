# Gradientes y detección de bordes

Código didáctico asociado al apartado correspondiente de la wiki. Las versiones Python y C++ persiguen el mismo objetivo conceptual; no tienen por qué ser traducciones línea por línea.

## Ejecutar Python

```bash
python3 07_gradientes_bordes/python/main.py
```

## Compilar C++

```bash
cmake -S 07_gradientes_bordes/cpp -B build/07_gradientes_bordes
cmake --build build/07_gradientes_bordes
./build/07_gradientes_bordes/opencv_07_gradientes_bordes
```

> Ajusta los nombres/rutas de entrada descritos en el código. Las imágenes y vídeos seleccionados para la wiki se guardarán en `../assets/07_gradientes_bordes/` cuando se prepare la fase visual.
