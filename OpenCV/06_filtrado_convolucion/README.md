# Filtrado, convolución y ruido

Código didáctico asociado al apartado correspondiente de la wiki. Las versiones Python y C++ persiguen el mismo objetivo conceptual; no tienen por qué ser traducciones línea por línea.

## Ejecutar Python

```bash
python3 06_filtrado_convolucion/python/main.py
```

## Compilar C++

```bash
cmake -S 06_filtrado_convolucion/cpp -B build/06_filtrado_convolucion
cmake --build build/06_filtrado_convolucion
./build/06_filtrado_convolucion/opencv_06_filtrado_convolucion
```

> Ajusta los nombres/rutas de entrada descritos en el código. Las imágenes y vídeos seleccionados para la wiki se guardarán en `../assets/06_filtrado_convolucion/` cuando se prepare la fase visual.
