# Transformada de Hough

Código didáctico asociado al apartado correspondiente de la wiki. Las versiones Python y C++ persiguen el mismo objetivo conceptual; no tienen por qué ser traducciones línea por línea.

## Ejecutar Python

```bash
python3 12_hough/python/main.py
```

## Compilar C++

```bash
cmake -S 12_hough/cpp -B build/12_hough
cmake --build build/12_hough
./build/12_hough/opencv_12_hough
```

> Ajusta los nombres/rutas de entrada descritos en el código. Las imágenes y vídeos seleccionados para la wiki se guardarán en `../assets/12_hough/` cuando se prepare la fase visual.
