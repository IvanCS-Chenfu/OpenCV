# Triangulación 3D

Código didáctico asociado al apartado correspondiente de la wiki. Las versiones Python y C++ persiguen el mismo objetivo conceptual; no tienen por qué ser traducciones línea por línea.

## Ejecutar Python

```bash
python3 20_triangulacion/python/main.py
```

## Compilar C++

```bash
cmake -S 20_triangulacion/cpp -B build/20_triangulacion
cmake --build build/20_triangulacion
./build/20_triangulacion/opencv_20_triangulacion
```

> Ajusta los nombres/rutas de entrada descritos en el código. Las imágenes y vídeos seleccionados para la wiki se guardarán en `../assets/20_triangulacion/` cuando se prepare la fase visual.
