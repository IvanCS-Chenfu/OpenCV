# Contornos, componentes y momentos

Código didáctico asociado al apartado correspondiente de la wiki. Las versiones Python y C++ persiguen el mismo objetivo conceptual; no tienen por qué ser traducciones línea por línea.

## Ejecutar Python

```bash
python3 11_contornos_componentes/python/main.py
```

## Compilar C++

```bash
cmake -S 11_contornos_componentes/cpp -B build/11_contornos_componentes
cmake --build build/11_contornos_componentes
./build/11_contornos_componentes/opencv_11_contornos_componentes
```

> Ajusta los nombres/rutas de entrada descritos en el código. Las imágenes y vídeos seleccionados para la wiki se guardarán en `../assets/11_contornos_componentes/` cuando se prepare la fase visual.
