# ORB

Código didáctico asociado al apartado correspondiente de la wiki. Las versiones Python y C++ persiguen el mismo objetivo conceptual; no tienen por qué ser traducciones línea por línea.

## Ejecutar Python

```bash
python3 15_orb/python/main.py
```

## Compilar C++

```bash
cmake -S 15_orb/cpp -B build/15_orb
cmake --build build/15_orb
./build/15_orb/opencv_15_orb
```

> Ajusta los nombres/rutas de entrada descritos en el código. Las imágenes y vídeos seleccionados para la wiki se guardarán en `../assets/15_orb/` cuando se prepare la fase visual.
