# Nubes de puntos: creación, lectura y visualización

Código didáctico asociado al apartado correspondiente de la wiki. Ajusta las rutas de entrada a tus propios datos o a los datasets documentados en `/datasets`.

## Ejecutar Python

```bash
python3 01_fundamentos/python/main.py
```

## Compilar C++

```bash
cmake -S 01_fundamentos/cpp -B build/01_fundamentos
cmake --build build/01_fundamentos
./build/01_fundamentos/open3d_01_fundamentos
```

Los resultados seleccionados se almacenarán en `../assets/01_fundamentos/` en la fase dedicada a imágenes y vídeos.
