# Poisson, Ball Pivoting y Alpha Shapes

Código didáctico asociado al apartado correspondiente de la wiki. Ajusta las rutas de entrada a tus propios datos o a los datasets documentados en `/datasets`.

## Ejecutar Python

```bash
python3 11_reconstruccion_superficies/python/main.py
```

## Compilar C++

```bash
cmake -S 11_reconstruccion_superficies/cpp -B build/11_reconstruccion_superficies
cmake --build build/11_reconstruccion_superficies
./build/11_reconstruccion_superficies/open3d_11_reconstruccion_superficies
```

Los resultados seleccionados se almacenarán en `../assets/11_reconstruccion_superficies/` en la fase dedicada a imágenes y vídeos.
