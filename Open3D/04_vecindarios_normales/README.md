# KD-tree, vecindarios y normales

Código didáctico asociado al apartado correspondiente de la wiki. Ajusta las rutas de entrada a tus propios datos o a los datasets documentados en `/datasets`.

## Ejecutar Python

```bash
python3 04_vecindarios_normales/python/main.py
```

## Compilar C++

```bash
cmake -S 04_vecindarios_normales/cpp -B build/04_vecindarios_normales
cmake --build build/04_vecindarios_normales
./build/04_vecindarios_normales/open3d_04_vecindarios_normales
```

Los resultados seleccionados se almacenarán en `../assets/04_vecindarios_normales/` en la fase dedicada a imágenes y vídeos.
