# Submuestreo y eliminación de outliers

Código didáctico asociado al apartado correspondiente de la wiki. Ajusta las rutas de entrada a tus propios datos o a los datasets documentados en `/datasets`.

## Ejecutar Python

```bash
python3 05_muestreo_outliers/python/main.py
```

## Compilar C++

```bash
cmake -S 05_muestreo_outliers/cpp -B build/05_muestreo_outliers
cmake --build build/05_muestreo_outliers
./build/05_muestreo_outliers/open3d_05_muestreo_outliers
```

Los resultados seleccionados se almacenarán en `../assets/05_muestreo_outliers/` en la fase dedicada a imágenes y vídeos.
