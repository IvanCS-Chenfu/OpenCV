# Mallas, muestreo y ray casting

Código didáctico asociado al apartado correspondiente de la wiki. Ajusta las rutas de entrada a tus propios datos o a los datasets documentados en `/datasets`.

## Ejecutar Python

```bash
python3 13_mesh_raycasting/python/main.py
```

## Compilar C++

```bash
cmake -S 13_mesh_raycasting/cpp -B build/13_mesh_raycasting
cmake --build build/13_mesh_raycasting
./build/13_mesh_raycasting/open3d_13_mesh_raycasting
```

Los resultados seleccionados se almacenarán en `../assets/13_mesh_raycasting/` en la fase dedicada a imágenes y vídeos.
